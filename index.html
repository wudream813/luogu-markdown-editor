📖 洛谷官方题解规范与 Markdown / LaTeX 速查手册

🛡️ 《洛谷主题库题解规范》与《专栏推荐规范》完整细则（审核必读）：

  • 1. 基本标点与空格规范：
    • 正确使用全角中文标点，句末必须有标点符号（特别地，句末要有句号 。）。
    • 中文汉字 与 英文单词、数字或 LaTeX 公式 之间必须以半角空格隔开（如 设 $n$ 为正整数、前 10 个元素、使用 C++ 语言）。
    • 中文标点符号 与 英文、数字或公式 之间【严格严禁有空格】（如 $n \le 10^5$， 正确，$n \le 10^5$ ， 违规）。
  • 2. 数学公式与 LaTeX 规范：
    • 数学公式（变量字母如 $i, j, n$、运算式、大 $\mathcal{O}$ 复杂度）必须使用 LaTeX；非数学公式（英文单词、算法名如 DFS/BFS、题目名）不应使用 LaTeX。
    • 同一个数学公式必须写在同一个 LaTeX 环境内，严禁将一个公式拆分成多个独立的 $ 碎拼（如 $a$ + $b$ = $c$ 违规，应为 $a + b = c$）。
    • 数学语言而非代码语言：
      • 比较符号：必须用 $\le$ (\le)、$\ge$ (\ge)、$\ne$ (\ne)，严禁使用 <=, >=, !=, ==。
      • 乘法符号：必须用 $\times$ (\times) 或 $\cdot$ (\cdot)，严禁在正文中用 * 代替乘号。
      • 赋值与推导：赋值用 $\gets$ (\gets) 或 $\to$ (\to)；推导因果用 $\implies$ (\implies) 或 $\Leftarrow, \Rightarrow$。
      • 整除与取模：整除使用 $\lfloor \frac{a}{b} \rfloor$，取模使用 $\bmod$ (\bmod)，同余使用 $\equiv$ (\equiv) 与 $\pmod p$ (\pmod p)。
      • 算法复杂度：大 O 记号中不应带有常数，常量用字母表示（如 $\mathcal{O}(n \log n)$、$\mathcal{O}(V + E)$），严禁写为纯文本 O(n)。
      • 科学计数法：大数字使用科学计数法表示（如 $5 \times 10^9$，不写 5e9）。
      • 函数名正体：$\gcd, \max, \min, \log, \det$，自定义函数使用 $\operatorname{lcm}$ (\operatorname{lcm})。
      • 矩阵与分段：连等式使用 \aligned，分段函数使用 \cases，矩阵使用 \bmatrix 或 \pmatrix。
  • 3. 代码块与引用规范：
    • 代码必须使用 Markdown 行间代码块引用，并显式指定编程语言（如 ```cpp、```python）。
    • 题解需附带代码实现，过长代码建议使用折叠框（:::info[代码实现]{open}）收起，保持题解清爽。
    • 题解如需配图必须上传至洛谷图床（动图可使用 Bilibili 嵌入），严禁使用易失效的外部链接。
  • 4. 题解内容要求：
    • 题解应包含核心思路、算法原理、重要结论证明与复杂度分析。
    • 严禁出现无意义闲聊或求过言论（如“求管理员通过”、“蒟蒻的第一篇题解”、“求赞”等），否则直接拒稿。
    • 引用他人内容必须使用链接标注来源；严禁使用生成式 AI 生成核心思路与代码。

⌨️ Windows 快捷键：

  • Ctrl + S：保存 Markdown 到本地
  • Ctrl + B：加粗文本
  • Ctrl + I：斜体文本
  • Ctrl + K：插入超链接
  • Ctrl + Shift + K：插入行内数学公式 $
  • Ctrl + Shift + M：插入行间数学公式 $$
  • Ctrl + Z / Ctrl + Y：撤销 / 重做
  • Tab / Shift + Tab：增加 / 减少 4 空格缩进
